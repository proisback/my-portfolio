- Each stop **collects** a stamp. The passport fills up as you fly, and the thesis shows the full page. That's how the logos become part of the story: you watch the collection grow.

- The stamp replaces the org text line. Alt text carries the full name ("Standard Chartered GBS").
- Motion: a 200 ms scale-and-settle "thud". Reduced motion gets the stamp already in place.

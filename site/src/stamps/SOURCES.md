# Passport stamp logos

Official artwork only. Nothing here is hand-drawn or traced. Each SVG was reduced to a single `currentColor` ink with a tight viewBox (fills, classes, styles and animations stripped; path coordinates rounded to display precision, shapes unchanged), so it inverts with the blueprint-to-colour theme. Rule: a stamp shows the name on the card, which is the mark from when Prateek was there.
